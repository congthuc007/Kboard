# Kboard Release v1.1.4 (versionCode 6)

## Điểm mới trong phiên bản v1.1.4:
1. **Thương hiệu & Tên ứng dụng mới:** Đổi tên chính thức thành **Kboard** (Bàn phím hệ thống: `Kboard LAN Keyboard`).
2. **Cập nhật Logo Full-Bleed:** Xử lý viền trắng trên các giao diện Android (MIUI, HyperOS, OneUI, Pixel).
3. **Phím tắt trong App Clone:** Hỗ trợ các tổ hợp phím `Ctrl+C`, `Ctrl+V`, `Ctrl+A`, `Ctrl+X`, `Ctrl+Z` qua `InputMethodService`.
4. **Bộ gõ Tiếng Việt Telex tích hợp:** Tự động bỏ dấu tiếng Việt với nút chuyển đổi `[ Telex: BẬT ]` / `[ Telex: TẮT ]`.
5. **Đè phím lặp ký tự (Hardware Key Repeat):** Giữ phím quá 380ms sẽ lặp ký tự theo chu kỳ 45ms (~22 ký tự/giây) tương tự phím vật lý.
6. **Làm sạch mã nguồn:** Loại bỏ các định danh hardcode và các icon emoji.

## Tệp đính kèm trong thư mục:
* `Kboard_v1.1.4.apk`: Bản cài đặt Android (API 28+).
* `Kboard.apk`: File cài đặt chuẩn.
* `Kboard_Receiver.exe`: Bộ nhận phím độc lập cho máy tính Windows (đã tích hợp icon mới).
